ARTEMIS Chile Lite para macOS (Intel + Apple Silicon) e iOS/iPadOS — desarrollada por Javiera Navarrete.
Necesita un Mac con Xcode: brew install xcodegen && ./preparar-web.sh && xcodegen generate && open ARTEMISLite.xcodeproj
Elige el esquema «ARTEMISLite-macOS» (o iOS), tu equipo de desarrollo y compila. Distribuir requiere una cuenta de Apple Developer.
Este proyecto NO se pudo compilar desde Linux: es el mismo anfitrión que usan las otras apps, con otra configuración.
